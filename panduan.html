Panduan Penggunaan & Cara Pemasangan

Halaman ini berisi petunjuk ringkas untuk memasang ekstensi di browser dan cara menggunakannya untuk mencari author SINTA maupun Scopus.

⚡ Tanpa Instal Software Tambahan: Anda tidak perlu menginstal Python, Node.js, atau mengetik perintah apapun di terminal. Cukup pasang di Google Chrome (atau Microsoft Edge).
1. Cara Pasang di Browser 2. Pencarian SINTA 3. Pencarian Scopus 4. Salin ke Excel / CSV 5. Masalah Umum (FAQ)

1. Cara Memasang Ekstensi (Hanya 1 Kali)

Pemasangan memakan waktu kurang dari 1 menit di laptop Anda maupun rekan kerja:

🍎 Untuk Pengguna MacBook (macOS)
  1. Ekstrak file .zip jika masih terkompresi (biasanya tersimpan di folder Downloads).
  2. Buka Google Chrome di MacBook.
  3. Di kolom alamat (URL bar), ketik:
    chrome://extensions lalu tekan Enter.
  4. Di pojok kanan atas layar, nyalakan toggle Developer mode.
  5. Di pojok kiri atas, klik tombol Load unpacked.
  6. Pilih folder hasil ekstrak tadi (folder yang berisi file manifest.json).
🪟 Untuk Pengguna Windows
  1. Klik kanan file .zip $\rightarrow$ pilih Extract All... ke folder biasa.
  2. Buka browser Google Chrome (atau Edge).
  3. Di kolom alamat (URL bar), ketik:
    chrome://extensions lalu tekan Enter.
  4. Di pojok kanan atas layar, nyalakan switch Developer mode.
  5. Di pojok kiri atas, klik tombol Load unpacked.
  6. Pilih folder hasil ekstrak tadi.
📌 Tips Pin Ekstensi: Klik icon puzzle (gambar potongan puzzle) di pojok kanan atas Chrome, lalu klik icon pin di sebelah "Pencari Author SINTA & Scopus" agar icon ekstensi selalu muncul di toolbar.

2. Cara Menggunakan Pencarian SINTA

Tab SINTA digunakan untuk mencari profil author pada portal resmi SINTA Kemdiktisaintek beserta metrik sitasinya (Skor 3 Tahun, Skor Total, H-Index Scopus, Scholar, dan WOS).

  1. Klik icon ekstensi di toolbar Chrome untuk membuka halaman Dashboard.
  2. Pastikan tab [ 🏛️ SINTA ] aktif.
  3. Masukkan daftar nama di kolom teks (satu baris untuk setiap nama).
    Contoh: 
    Dr. Tio Haidar Hanif, M.Kom.
Prof. Ir. Budi Santoso, M.Sc., Ph.D.
Siti Aminah, S.Pd., M.Pd.
  4. Pengaturan Tambahan (Opsional):
    • Bersihkan Gelar: Disarankan selalu dicentang agar gelar (seperti Prof, Dr, M.Kom, S.T.) diabaikan saat mencari, namun nama asli tetap tercatat.
    • Filter Kampus: Masukkan potongan nama perguruan tinggi jika ingin mempersempit hasil (contoh: Universitas Indonesia atau Gadjah Mada).
    • Hapus Duplikat: Menghapus nama ganda secara otomatis sebelum pencarian dimulai.
  5. Klik tombol "▶ Mulai Pencarian SINTA".
⚠️ Jika Muncul Status "Perlu Konfirmasi" (Kuning):
Artinya sistem menemukan lebih dari satu kandidat di SINTA. Klik tombol "Pilih Kandidat" pada baris nama tersebut, lalu pilih profil yang tepat berdasarkan nama kampus/departemennya. Jika tidak ada yang cocok, klik "Tidak Ada yang Benar".

3. Cara Menggunakan Pencarian SCOPUS

Tab Scopus digunakan untuk mencari profil author internasional, Scopus Author ID, afiliasi kampus, negara, jumlah dokumen terindeks, dan h-index Scopus.

  1. Buka dashboard ekstensi, lalu klik tab [ 🔬 SCOPUS ].
  2. Masukkan daftar nama pada kolom teks.
  3. Pemisahan Nama Otomatis:
    Sistem akan otomatis memecah nama menjadi First Name dan Last Name sesuai kaidah pencarian Scopus internasional.
    Contoh: Dr. Tio Haidar Hanif, M.Kom. $\rightarrow$ Last Name: Hanif, First Name: Tio Haidar.
  4. Klik tombol "▶ Mulai Pencarian Scopus".
  5. Cara Kerja di Latar Belakang:
    Ekstensi akan membuka satu tab Scopus di browser secara otomatis, mengambil data yang diperlukan, dan otomatis menutup tab tersebut setelah pencarian selesai. Anda tidak perlu menyentuh tab Scopus yang terbuka.
💡 Catatan Akses Scopus:
Pencarian profil author Scopus bersifat publik. Namun jika Anda berada di jaringan kampus (WiFi kampus atau VPN kampus dengan langganan Scopus), detail afiliasi biasanya akan tampil lebih lengkap.

4. Cara Memindahkan Hasil ke Excel / Spreadsheet

Setelah pencarian selesai, Anda memiliki dua cara praktis untuk mengambil datanya:

📋 Opsi 1: Salin Tabel (Langsung Paste ke Excel)
  1. Klik tombol "📋 Salin Tabel" di pojok kanan atas tabel hasil.
  2. Buka aplikasi Microsoft Excel atau Google Sheets.
  3. Pilih sel pertama (A1), lalu tekan:
    Ctrl + V (di Windows) atau Cmd ⌘ + V (di Mac)
  4. Semua baris dan kolom akan langsung terisi rapi dengan header yang sesuai.
📥 Opsi 2: Unduh File CSV
  1. Klik tombol "📥 Unduh CSV".
  2. File bernama hasil_author_sinta_....csv atau hasil_author_scopus_....csv akan otomatis terunduh ke komputer Anda.
  3. File sudah menggunakan format standar UTF-8 BOM sehingga huruf dan karakter Indonesia tidak akan rusak saat dibuka di Excel.

5. Pertanyaan & Masalah yang Sering Muncul (FAQ)

Q: Apakah rekan saya harus menginstal Python / Node.js?

Tidak sama sekali. Seluruh aplikasi berjalan langsung di dalam browser Google Chrome. Teman Anda hanya butuh folder ekstensi ini dan memuatnya via chrome://extensions.

Q: Mengapa hasil pencarian statusnya "Tidak Ditemukan"?

Beberapa kemungkinan penyebabnya:

  • Ejaan nama berbeda dengan yang terdaftar di SINTA atau Scopus (misal: penulisan singkatan nama seperti Moh. vs Muhammad).
  • Filter kampus terlalu ketat atau penulisan nama kampusnya berbeda. Coba kosongkan kolom filter kampus.
  • Nama tersebut memang belum terdaftar di portal SINTA / Scopus.

Q: Mengapa ada jeda 1 detik di antara setiap nama yang dicari?

Jeda (delay) ini sengaja dibuat agar server SINTA dan Scopus tidak menganggap aktivitas pencarian sebagai serangan spam (DDoS). Anda bisa menyesuaikan durasi jeda (800 ms hingga 2000 ms) di kolom pengaturan.

Q: Apakah data nama yang saya cari tersimpan di internet?

Tidak. Aplikasi ini berjalan 100% lokal di browser Anda (*client-side*). Data tidak dikirimkan ke server pengembang manapun, melainkan hanya berkomunikasi langsung antara browser Anda dengan web resmi SINTA dan Scopus.
