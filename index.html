Pencari Author SINTA & Scopus
Dashboard Aplikasi Repositori GitHub

Panduan Pemasangan dan Penggunaan Ekstensi

Ekstensi Google Chrome untuk mencari profil author pada pangkalan data SINTA Kemdiktisaintek dan Scopus Elsevier. Ekstensi ini berjalan langsung di dalam peramban web tanpa memerlukan instalasi perangkat lunak tambahan seperti Python atau Node.js.

1. Pemasangan di Google Chrome (Hanya Dilakukan Sekali)

Unduh file ZIP dari tombol di atas, kemudian ikuti langkah berikut sesuai sistem operasi laptop yang digunakan:

  1. Unduh file ZIP dari GitHub melalui tombol di atas.
  2. Klik kanan file ZIP, pilih Extract All..., lalu tentukan folder tujuan.
  3. Buka Google Chrome (atau Microsoft Edge).
  4. Ketik chrome://extensions pada bilah alamat lalu tekan Enter.
  5. Aktifkan sakelar Developer mode di sudut kanan atas.
  6. Klik tombol Load unpacked di sudut kiri atas.
  7. Pilih folder hasil ekstrak (folder Pencari-Author-main).

Setelah terpasang, klik ikon ekstensi (berbentuk puzzle) di bilah kanan atas Google Chrome, lalu sematkan (pin) agar tombol aplikasi selalu terlihat.

2. Cara Menggunakan Pencarian SINTA

Tab SINTA digunakan untuk mencari profil author pada portal resmi SINTA Kemdiktisaintek, termasuk skor 3 tahun, skor total, H-index Scopus, Google Scholar, dan WOS.

  1. Buka dashboard ekstensi dengan mengklik ikon pada toolbar browser.
  2. Pilih tab SINTA.
  3. Ketik atau tempel daftar nama pada kolom input teks (satu nama per baris), contoh: 
    Dr. Tio Haidar Hanif, M.Kom.
Prof. Ir. Budi Santoso, M.Sc., Ph.D.
Siti Aminah, S.Pd., M.Pd.
  4. Tentukan opsi pencarian:
    • Bersihkan Gelar: Disarankan selalu aktif agar gelar akademik diabaikan saat pencarian sehingga hasil lebih akurat, sementara nama asli tetap tersimpan di tabel hasil.
    • Filter Kampus: Masukkan nama perguruan tinggi jika ingin menyaring author hanya dari kampus tertentu. Kosongkan jika ingin mencari di seluruh kampus.
    • Hapus Duplikat: Menghilangkan entri nama ganda sebelum pencarian diproses.
    • Jeda Antar Permintaan: Jeda waktu default 1 detik per nama untuk menjaga kestabilan permintaan ke server SINTA.
  5. Klik tombol Mulai Pencarian SINTA.
Status Perlu Konfirmasi: Jika ditemukan beberapa kandidat author dengan nama yang serupa, status baris akan berwarna kuning (Perlu Konfirmasi). Klik tombol Pilih Kandidat pada baris tersebut untuk memilih profil yang benar, atau klik Tidak Ada yang Benar jika bukan profil yang dicari.

3. Cara Menggunakan Pencarian Scopus

Tab Scopus digunakan untuk mencari data profil author di Scopus Elsevier, termasuk Scopus Author ID, afiliasi, kota, negara, jumlah dokumen terindeks, dan h-index Scopus.

  1. Pilih tab Scopus pada dashboard ekstensi.
  2. Masukkan daftar nama pada kolom input teks.
  3. Sistem akan otomatis memisahkan nama menjadi Nama Depan (First Name) dan Nama Belakang (Last Name) sesuai struktur pencarian baku Scopus.
  4. Klik tombol Mulai Pencarian Scopus.
  5. Ekstensi akan membuka satu tab Scopus di latar belakang untuk membaca data hasil pencarian secara otomatis, dan menutup tab tersebut setelah seluruh antrian selesai.
Catatan Jaringan: Pencarian author Scopus dapat diakses dari jaringan publik. Jika perangkat Anda terhubung ke jaringan atau VPN kampus yang berlangganan Scopus, rincian profil biasanya akan disajikan lebih lengkap oleh Elsevier.

4. Menyalin Hasil ke Excel atau Google Sheets

Setelah pencarian selesai, data tabel dapat dipindahkan menggunakan salah satu dari dua metode:

  • Salin Tabel: Klik tombol Salin Tabel di atas tabel hasil. Buka Microsoft Excel atau Google Sheets, pilih sel A1, lalu tekan Ctrl + V (di Windows) atau Cmd + V (di macOS). Semua data akan tertata rapi pada kolom masing-masing.
  • Unduh CSV: Klik tombol Unduh CSV untuk mengunduh file spreadsheet berformat standar UTF-8 BOM yang dapat langsung dibuka di Microsoft Excel tanpa masalah karakter encoding.

5. Catatan Teknis dan Kendala Umum

Apakah rekan kerja saya harus menginstal perangkat lunak lain?

Tidak. Seluruh fungsionalitas berjalan murni sebagai ekstensi di dalam peramban Google Chrome atau Microsoft Edge. Tidak diperlukan instalasi Python, pip, Node.js, atau penggunaan terminal.

Mengapa status author "Tidak Ditemukan"?

Beberapa hal yang dapat diperiksa:

  • Perbedaan ejaan antara nama yang dimasukkan dengan yang terdaftar di basis data (misalnya singkatan nama).
  • Filter nama kampus terlalu spesifik atau penulisan nama kampusnya berbeda. Coba kosongkan kolom filter kampus.
  • Author yang bersangkutan memang belum terdaftar di pangkalan data SINTA atau Scopus.

Bagaimana privasi dan keamanan data?

Seluruh proses pencarian berlangsung secara lokal di peramban komputer pengguna. Data nama tidak pernah dikirim ke server pengembang atau pihak ketiga mana pun selain langsung ke web resmi SINTA dan Scopus.
