Pencari Author SINTA, GARUDA & Scopus
Dashboard Aplikasi Repositori GitHub

Panduan Pemasangan dan Penggunaan Ekstensi

Ekstensi Google Chrome untuk mencari profil author pada pangkalan data SINTA Kemdiktisaintek, GARUDA (Garba Rujukan Digital), dan Scopus Elsevier. Ekstensi ini berjalan langsung di dalam peramban web tanpa memerlukan instalasi perangkat lunak tambahan seperti Python atau Node.js.

1. Pemasangan di Google Chrome (Hanya Dilakukan Sekali)

Unduh file ZIP dari tombol di atas, kemudian ikuti langkah berikut:

  1. Unduh file ZIP dari GitHub melalui tautan di atas.
  2. Klik kanan file ZIP, pilih Extract All... (atau unzip di macOS), lalu tentukan folder tujuan.
  3. Buka Google Chrome (atau Microsoft Edge).
  4. Ketik chrome://extensions pada bilah alamat lalu tekan Enter.
  5. Aktifkan sakelar Developer mode (Mode pengembang) di sudut kanan atas.
  6. Klik tombol Load unpacked (Muat yang belum dibongkar) di sudut kiri atas.
  7. Pilih folder hasil ekstrak (folder Pencari-Author-main).

Setelah terpasang, klik ikon ekstensi (berbentuk puzzle) di bilah kanan atas Google Chrome, lalu sematkan (pin) agar tombol aplikasi selalu terlihat.

2. Cara Menggunakan Pencarian Gabungan (Semua Sumber)

Mode Semua Sumber (Gabungan) adalah fitur utama yang memungkinkan Anda mencari ke SINTA, GARUDA, dan SCOPUS sekaligus dalam satu proses. Hasil pencarian akan disajikan dalam satu baris per orang dengan kolom terpisah untuk masing-masing basis data.

  1. Buka dashboard ekstensi, pastikan tab Semua Sumber (Gabungan) aktif (secara default sudah terpilih).
  2. Tempel daftar nama pada kolom input teks (satu nama per baris).
  3. Tentukan jeda waktu (disarankan 1.5 detik per nama untuk stabilitas koneksi ketiga sumber data).
  4. Klik tombol Mulai Pencarian Semua Sumber.
  5. Sistem akan memproses tiap nama secara berurutan: mencari ke SINTA, lalu ke GARUDA, lalu ke SCOPUS.
  6. Memilih / Mengganti Kandidat Independen: Pada baris hasil, tiap kolom (SINTA, GARUDA, SCOPUS) memiliki tombol [Pilih] atau [Ganti] sendiri. Jika salah satu sumber memiliki beberapa kandidat nama yang serupa, Anda cukup mengklik tombol di kolom tersebut untuk menentukan kandidat yang benar tanpa mengganggu data sumber lainnya.
Ekspor 1 Baris Lengkap: Saat Anda mengklik Salin Tabel atau Unduh CSV dalam mode ini, satu baris di Excel langsung berisi ID, nama, skor, jumlah dokumen, dan link profil dari SINTA + GARUDA + SCOPUS secara bersamaan!

3. Fitur Reverse Lookup: Dari Scopus ID ke SINTA & GARUDA

Punya daftar Scopus Author ID atau tautan profil Scopus dan ingin mencari akun SINTA dan GARUDA-nya secara otomatis? Anda dapat menggunakan sakelar Reverse via Scopus ID.

  1. Pada Bagian 1 Input Dashboard, klik tombol sakelar Reverse via Scopus ID (Otomatis ke SINTA & GARUDA).
  2. Masukkan daftar Scopus Author ID atau link profil Scopus (satu per baris), contoh: 
    60611357400
57193231456
https://www.scopus.com/authid/detail.uri?authorId=57208922904
  3. Klik tombol Mulai Reverse Lookup (Scopus ➔ SINTA & GARUDA).
  4. Cara Kerja Otomatis:
    • Ekstensi membuka halaman profil author Scopus di latar belakang dan membaca nama lengkap author, afiliasi kampus, jumlah dokumen, dan h-index.
    • Format nama Scopus seperti Hanif, Tio Haidar otomatis dibalik menjadi Tio Haidar Hanif.
    • Nama lengkap tersebut langsung dipakai untuk mencari author di SINTA dan GARUDA.
    • Data ketiga sumber ditampilkan dalam satu baris tabel utuh dengan pencocokan 100% pada kolom Scopus dan kandidat terbaik pada kolom SINTA & GARUDA.

4. Cara Menggunakan Pencarian SINTA

Tab SINTA digunakan khusus jika Anda hanya ingin mencari profil author pada portal resmi SINTA Kemdiktisaintek.

  1. Pilih tab SINTA Kemdiktisaintek pada dashboard ekstensi.
  2. Ketik atau tempel daftar nama pada kolom input teks (satu nama per baris), contoh: 
    Dr. Tio Haidar Hanif, M.Kom.
Prof. Ir. Budi Santoso, M.Sc., Ph.D.
Siti Aminah, S.Pd., M.Pd.
  3. Tentukan opsi pencarian:
    • Bersihkan Gelar: Disarankan selalu aktif agar gelar akademik diabaikan saat pencarian sehingga hasil lebih akurat, sementara nama asli tetap tersimpan di tabel hasil.
    • Filter Kampus: Masukkan nama perguruan tinggi jika ingin menyaring author hanya dari kampus tertentu. Kosongkan jika ingin mencari di seluruh kampus.
    • Hapus Duplikat: Menghilangkan entri nama ganda sebelum pencarian diproses.
    • Jeda Antar Permintaan: Jeda waktu default 1 detik per nama.
  4. Klik tombol Mulai Pencarian SINTA.

5. Cara Menggunakan Pencarian GARUDA

Tab GARUDA digunakan khusus untuk mencari profil author pada portal resmi Garba Rujukan Digital (GARUDA) Kemdiktisaintek (garuda.kemdiktisaintek.go.id).

  1. Pilih tab GARUDA Kemdiktisaintek pada dashboard ekstensi.
  2. Ketik atau tempel daftar nama pada kolom input teks (satu nama per baris).
  3. Klik tombol Mulai Pencarian Garuda.
  4. Hasil pencarian akan memunculkan Nama di Garuda, Garuda ID, Afiliasi, Jumlah Dokumen, dan tautan langsung ke profil.

6. Cara Menggunakan Pencarian Scopus

Tab Scopus digunakan khusus jika Anda hanya ingin mencari data profil author di Scopus Elsevier (Scopus Author ID, afiliasi, kota, negara, dokumen, dan h-index).

  1. Pilih tab SCOPUS (Elsevier) pada dashboard ekstensi.
  2. Masukkan daftar nama pada kolom input teks.
  3. Klik tombol Mulai Pencarian Scopus.

7. Menyalin Hasil ke Excel atau Google Sheets

Setelah pencarian selesai, data tabel dapat dipindahkan menggunakan salah satu dari dua metode:

  • Salin Tabel: Klik tombol Salin Tabel di atas tabel hasil. Buka Microsoft Excel atau Google Sheets, pilih sel A1, lalu tekan Ctrl + V (di Windows) atau Cmd + V (di macOS). Semua data akan tertata rapi pada kolom masing-masing.
  • Unduh CSV: Klik tombol Unduh CSV untuk mengunduh file spreadsheet berformat standar UTF-8 BOM yang dapat langsung dibuka di Microsoft Excel tanpa masalah karakter encoding.

8. Catatan Teknis dan Kendala Umum

Mengapa status author "Tidak Ditemukan"?

Beberapa hal yang dapat diperiksa:

  • Perbedaan ejaan antara nama yang dimasukkan dengan yang terdaftar di basis data (misalnya singkatan nama).
  • Filter nama kampus terlalu spesifik atau penulisan nama kampusnya berbeda. Coba kosongkan kolom filter kampus.
  • Author yang bersangkutan memang belum terdaftar di pangkalan data SINTA, GARUDA, atau Scopus.
