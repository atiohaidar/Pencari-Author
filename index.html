1. Cara Memasang Ekstensi (Hanya 1 Menit)

Cukup lakukan langkah berikut satu kali saja di laptop Anda atau rekan kerja:

🍎 Untuk Pengguna MacBook (macOS)
  1. Klik tombol Download Ekstensi (.zip) di atas.
  2. Buka file .zip di Finder untuk mengekstraknya menjadi folder biasa.
  3. Buka browser Google Chrome.
  4. Ketik di kolom alamat:
    chrome://extensions lalu tekan Enter.
  5. Di pojok kanan atas, aktifkan toggle Developer mode (Mode pengembang).
  6. Di pojok kiri atas, klik tombol Load unpacked (Muat yang belum dibongkar).
  7. Pilih folder hasil ekstrak tadi. Selesai!
🪟 Untuk Pengguna Windows
  1. Klik tombol Download Ekstensi (.zip) di atas.
  2. Klik kanan file zip $\rightarrow$ pilih Extract All... ke folder biasa.
  3. Buka browser Google Chrome (atau Edge).
  4. Ketik di kolom alamat:
    chrome://extensions lalu tekan Enter.
  5. Di pojok kanan atas, nyalakan switch Developer mode.
  6. Di pojok kiri atas, klik tombol Load unpacked.
  7. Pilih folder hasil ekstrak tadi. Selesai!
📌 Tips Pin Icon di Toolbar Chrome:
Klik icon Puzzle di pojok kanan atas Google Chrome, lalu klik icon Pin di sebelah nama "Pencari Author SINTA & Scopus" agar icon selalu siap diklik di samping kolom alamat browser.

2. Cara Menggunakan Pencarian SINTA

Mencari data author di portal resmi SINTA Kemdiktisaintek lengkap dengan skor 3 tahun, skor total, H-index Scopus, Scholar, dan WOS.

  1. Klik icon ekstensi di toolbar Chrome untuk membuka halaman Dashboard.
  2. Pilih tab [ 🏛️ SINTA ].
  3. Masukkan daftar nama di kolom teks (satu baris untuk setiap nama). 
    Dr. Tio Haidar Hanif, M.Kom.
Prof. Ir. Budi Santoso, M.Sc., Ph.D.
Siti Aminah, S.Pd., M.Pd.
  4. Opsi Pengaturan:
    • Bersihkan Gelar Otomatis: Gelar seperti Prof, Dr, M.Kom, S.T. otomatis dibersihkan saat pencarian agar nama cocok di SINTA, namun nama asli tetap tercatat pada tabel hasil.
    • Filter Kampus: Masukkan nama universitas jika ingin menyaring author dari institusi tertentu saja (contoh: Universitas Indonesia). Dikosongkan jika ingin mencari ke semua kampus.
    • Hapus Duplikat: Menghilangkan nama ganda sebelum pencarian dimulai.
  5. Klik tombol "▶ Mulai Pencarian SINTA".
⚠️ Jika Muncul Status "Perlu Konfirmasi" (Kuning):
Artinya SINTA menemukan lebih dari satu kandidat dengan nama mirip. Klik tombol kuning "Pilih Kandidat" pada baris nama tersebut, lalu tentukan profil author yang sesuai. Jika bukan salah satunya, klik "Tidak Ada yang Benar".

3. Cara Menggunakan Pencarian SCOPUS

Mencari profil author di Scopus Elsevier untuk mendapatkan Scopus Author ID, afiliasi instansi, kota, negara, jumlah dokumen, dan h-index Scopus.

  1. Buka dashboard ekstensi, lalu pilih tab [ 🔬 SCOPUS ].
  2. Masukkan daftar nama pada kolom teks.
  3. Pemisahan Nama Otomatis:
    Sistem otomatis memecah nama menjadi First Name dan Last Name sesuai format baku pencarian Scopus internasional.
    Contoh: Dr. Tio Haidar Hanif, M.Kom. $\rightarrow$ Last: Hanif, First: Tio Haidar.
  4. Klik tombol "▶ Mulai Pencarian Scopus".
  5. Cara Kerja di Latar Belakang:
    Ekstensi akan membuka satu tab Scopus di browser secara otomatis untuk mengekstrak data yang dibutuhkan, dan menutupnya kembali setelah pencarian selesai. Anda tidak perlu mengutak-atik tab tersebut.
💡 Catatan Akses Jaringan:
Pencarian nama author Scopus dapat diakses secara publik. Namun jika Anda terhubung ke jaringan/WiFi/VPN kampus yang memiliki lisensi langganan Scopus, rincian afiliasi biasanya akan tampil lebih detail.

4. Cara Memindahkan Hasil ke Excel / Google Sheets

Tersedia dua opsi praktis setelah pencarian selesai:

📋 Opsi 1: Salin Tabel (Langsung Paste)
  1. Klik tombol "📋 Salin Tabel" di pojok kanan atas tabel hasil.
  2. Buka Microsoft Excel atau Google Sheets baru.
  3. Klik pada sel A1, lalu tekan:
    Ctrl + V (Windows) atau Cmd ⌘ + V (Mac)
  4. Seluruh kolom dan baris akan langsung rapi di sel masing-masing.
📥 Opsi 2: Unduh File CSV
  1. Klik tombol "📥 Unduh CSV".
  2. File bernama hasil_author_sinta_....csv atau hasil_author_scopus_....csv akan otomatis terunduh.
  3. File sudah berformat standar UTF-8 BOM, sehingga teks nama tidak akan rusak saat dibuka di Excel.

5. Pertanyaan & Kendala yang Sering Terjadi (FAQ)

Q: Apakah rekan saya harus menginstal Python / library apapun?

Tidak sama sekali. Ekstensi ini 100% menggunakan kapabilitas browser Chrome asli. Rekan Anda cukup mendownload zip, mengekstraknya, dan memuatnya di chrome://extensions.

Q: Mengapa hasil pencarian statusnya "Tidak Ditemukan"?

Kemungkinan penyebabnya:

  • Ejaan nama berbeda dengan yang tercantum di pangkalan data SINTA/Scopus (misal ada singkatan nama).
  • Filter kampus terlalu ketat atau berbeda ejaan. Coba kosongkan kolom filter kampus.
  • Nama tersebut memang belum terdaftar di database SINTA maupun Scopus.

Q: Mengapa ada jeda 1 detik di antara setiap nama?

Jeda (delay) ini sengaja dibuat agar server SINTA dan Scopus tidak memblokir IP laptop Anda karena dianggap sebagai bot atau serangan spam. Anda bisa mengatur durasi jeda di pengaturan (800 ms – 2000 ms).

Q: Apakah data nama yang saya cari aman?

Sangat aman. Seluruh proses pencarian berjalan 100% lokal di browser Anda (*client-side*). Data tidak pernah dikirim ke server pembuat atau pihak ketiga mana pun.
